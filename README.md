# Stock Market Predictor

A Machine Learning web application that predicts the next day's closing stock price using historical stock market data.

## Features

- Yahoo Finance Data
- Random Forest Regression
- Streamlit UI
- Actual vs Predicted Graph
- R² Score
- MAE
- RMSE

## Dataset

Downloaded dynamically using yfinance.

## Features Used

- Open
- High
- Low
- Volume
- Previous Close

## Target

Next Day Closing Price

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
